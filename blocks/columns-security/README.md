# columns-security

Custom **columns** block. Purpose: feature-tiles.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, 3 cells: image, H3, paragraph.

## Supported variations

No variations.

## Universal Editor fields

N/A (Document Authoring project)

## Behaviour notes

- Preferred: one row, one cell per column, each cell holding image, H3 and paragraph.
  Also accepted: one row per column with an image-only cell next to a text cell.
- The image always renders above the text in a square, rounded frame; a column without an
  image renders text only.
- Layout: 1 column on mobile; all columns in one row at 900px.
- The intro heading and the closing paragraph + "Explore Surface for Business" button are
  default content in the same section, not part of this block.
